# Static assets

Dat file mac dinh cua website vao cac thu muc sau:

- `logo/`: logo cong ty
- `partners/`: logo doi tac
- `banners/`: banner trang chu, banner section
- `Logo_TSVN/`: logo va hinh anh nhan dien chuong trinh
- `videos/`: video intro, trailer ngan

Duong dan su dung trong admin bat dau tu `/assets`.

Vi du:

- `public/assets/logo/company-logo.png` -> `/assets/logo/company-logo.png`
- `public/assets/banners/home-banner.jpg` -> `/assets/banners/home-banner.jpg`
- `public/assets/Logo_TSVN/Mockup_vàng.png` -> `/assets/Logo_TSVN/Mockup_v%C3%A0ng.png`
- `public/assets/videos/intro.mp4` -> `/assets/videos/intro.mp4`

Luu y: voi video lon, nen dung Supabase Storage/CDN thay vi commit truc tiep vao source.
